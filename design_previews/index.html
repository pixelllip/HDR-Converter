HDR Converter · 界面方向对比

三个方向都是同一功能的静态预览页（首页 / 图片视图 / 视频视图，可点击体验交互），
浏览器直接打开即可，无需运行 Electron。对比后告诉我选哪个，我把样式移植回 hdr_viewer.html。

方向 A

专业工具风

中性深灰 + 琥珀强调色（HDR = 亮度主题），线性 SVG 图标，无渐变无发光，像调色/母带处理台。

打开预览 → 方向 B

原生 Windows 11

跟随系统语义色（浅色/深色自适应，可手动切换），Mica 模糊工具栏，分段选项卡，系统强调色滑块。

打开预览 → 方向 C

最小改动

保留现在的深海军蓝主题，只去 emoji、去渐变、修正排版字号。与原版最接近，改动风险最低。

打开预览 → 方向 D

Material Design 3 · 全功能排版

按当前 hdr_viewer.html 已实现的全部功能（首页 / 图片三选项卡 / 批量队列 / 三种对比模式 / 视频视图）用 MD3 重新排版：Filled 控件、Primary Tabs、分段按钮；主题色自动跟随 Windows（systemPreferences.getAccentColor()），无需手动选色；视频侧参数按 输入输出/转换方式/画质色调/编码性能 折叠分组。
已拆分为独立页面：home / image / video + 共享 md3.css / md3.js
